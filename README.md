Sistemi për Menaxhimin e Klinikave Mjekësore

## Përshkrimi i projektit

Ky projekt ka për qëllim zhvillimin e një sistemi web për menaxhimin e klinikave mjekësore. Sistemi synon të lehtësojë menaxhimin e pacientëve, mjekëve dhe termineve mjekësore.

Projekti zhvillohet në kuadër të lëndës **Projekt - Praktikë Profesionale**.

## Teknologjitë e përdorura

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- Visual Studio Code
- Git dhe GitHub

## Funksionalitetet kryesore

- Regjistrimi dhe shfaqja e pacientëve.
- Ndryshimi dhe fshirja e të dhënave të pacientëve.
- Regjistrimi dhe shfaqja e mjekëve.
- Krijimi dhe menaxhimi i termineve mjekësore.
- Validimi i të dhënave të formularëve.

## Struktura e projektit

```text
menaxhimi-klinikave/
├── index.php
├── pacientet/
├── mjeket/
├── terminet/
├── includes/
├── config/
├── assets/
├── database/
├── docs/
└── README.md
```

## Baza e të dhënave

Emri i bazës së të dhënave: `klinika_db`.

Tabelat kryesore janë `Pacienti`, `Mjeku` dhe `Termini`.
